Interactive workspace

Practice controlling files, folders, and text

Browser security prevents a web page from controlling your real laptop files without permission. This safe workspace simulates the same interactions so gestures can select folders, open files, type text, and run shortcuts.

Important note

About full laptop control

A normal website cannot control every operating-system window, file, or folder directly. To control the full laptop, this gesture engine would need to be packaged as a trusted desktop app with accessibility permissions on Windows, macOS, or Linux. This project provides the browser prototype and interaction design for that app.
